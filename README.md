# Super Over League

A responsive React-based Super Over League interface featuring Royal Challengers Bengaluru (RCB) and Chennai Super Kings (CSK).

## Overview

This project was built to practice React fundamentals, JSX, CSS Flexbox, responsive design, and a professional Git/GitHub workflow.

## Features

- Responsive design for mobile and desktop screens
- RCB and CSK team images
- Centered and responsive layout using CSS Flexbox
- Mobile-specific responsive styling

## Tech Stack

- React
- JavaScript
- HTML
- CSS
- Flexbox

## Getting Started

### Run Locally

1. Clone the repository.
2. Open the project folder.
3. Open the project in the CCBP React development environment.
4. Run the application using the environment's preview/run option.
5. Verify the application in both desktop and mobile viewport sizes.

## Git Workflow

This project follows a feature-branch workflow.

```text
main
└── feature/<feature-name>
       ↓
     Code
       ↓
     Test
       ↓
  Review changes
       ↓
    Commit
       ↓
     Push
       ↓
  Pull Request
       ↓
     Review
       ↓
     Merge
```

The `main` branch is kept stable. Feature and documentation changes are developed in separate branches and merged through Pull Requests.
